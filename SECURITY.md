# Security policy

Vengeance stores sensitive information about your infrastructure. Please report vulnerabilities
privately through GitHub's **Report a vulnerability** button on this repository (Security tab),
not in public issues.

You can expect an acknowledgement within 72 hours and a fix or mitigation plan within 14 days for
confirmed issues. Fixed vulnerabilities are announced in the release notes with credit, unless
you prefer otherwise.

Supported versions: the latest minor release.
